# AI-Based Dynamic Tariff Optimization for EV Charging Networks

An Agentic AI framework that predicts EV charging demand, recommends dynamic tariffs in real time, and continuously monitors pricing outcomes to maximize revenue, balance grid demand, and optimize charger utilization.

## Project Overview

Static flat-rate pricing (Rs 15/kWh) for EV charging stations leads to peak-hour congestion, off-peak underutilization, and suboptimal revenue. This project builds three autonomous agents that work together to solve this:

1. **Demand Prediction Agent** — Forecasts station utilization using a Random Forest model trained on temporal and lagged features
2. **Tariff Pricing Agent** — Maps predicted demand to dynamic tariffs (surge/normal/discount) to shift load and increase revenue
3. **Monitoring & Learning Agent** — Tracks pricing efficiency, prediction accuracy, and wait time reduction across hourly episodes

```bash

pip install -r requirements.txt
```

### 2. Place raw data

Download the datasets and place them under `data/raw/` following the folder structure above.

### 3. Run the notebook

Open `notebooks/AI_Dynamic_Tariff_Workflow.ipynb` in Jupyter and run all cells. The notebook will:
- Load and preprocess both datasets
- Run EDA with visualizations
- Train the demand prediction model
- Apply dynamic tariff pricing
- Generate monitoring metrics
- Save all outputs to `outputs/`

## Datasets

### 1. ACN-Data (Adaptive Charging Network)
- **URL:** https://ev.caltech.edu/dataset.html
- **Coverage:** 30,000+ EV charging sessions from Caltech and JPL sites
- **Period:** April - December 2018
- **Use:** Session-level charging behavior analysis (timestamps, energy delivered, session duration, station IDs)

### 2. UrbanEV Dataset (ST-EVCDP)
- **URL:** https://github.com/IntelligentSystemsLab/ST-EVCDP
- **Coverage:** 24,798 charging piles with 5-minute interval data
- **Period:** June - July 2022
- **Use:** Temporal demand prediction, spatial charging patterns, and dynamic pricing pipeline

## Pricing Strategy

| Zone | Utilization | Multiplier | Tariff (Rs/kWh) | Purpose |
|------|------------|------------|-----------------|---------|
| Discount | <= 30% | 0.85x | 12.75 | Attract demand during off-peak |
| Normal | 30-80% | Linear | 12.75 - 22.50 | Smooth transition |
| Surge | >= 80% | 1.50x | 22.50 | Discourage congestion |

## Evaluation Metrics

| Agent | Metric | Description |
|-------|--------|-------------|
| Demand Prediction | RMSE, MAE, R² | Model accuracy evaluated strictly on a temporally isolated 20% holdout test set |
| Tariff Pricing | Revenue Gain % | Improvement over fixed Rs 15/kWh baseline (evaluated on ACN) |
| Tariff Pricing | Off-Peak Uplift | Session increase in discount zone (evaluated on UrbanEV test set) |
| Monitoring | Wait Time Reduction | Simulated queue proxy reduction in surge periods using assumed price elasticity |
| Monitoring | Pricing Efficiency | Revenue per kWh delivered over time |

## Assumptions & Limitations

- **Currency Integration:** All monetary values are simulated in Indian Rupees (Rs). Because the ACN data is from the USA and UrbanEV is from China, a Rs 15/kWh base tariff and Rs 6/kWh grid cost are assumed to simulate the Indian EV charging market scenario specified in the problem statement.
- **Localized Tariff Mapping:** Because ACN lacks real-time station utilization, ACN sessions receive dynamic tariffs based on a localized utilization proxy derived from ACN's own historical hourly volume, ensuring pricing accurately reflects site-specific workplace constraints rather than foreign urban demand curves.
- **Queue Proxy & Demand Elasticity (Causality):** Because historical users did not experience our dynamic prices, causal claims are avoided. Waiting time reductions and customer response rates are mathematically simulated using a standard Price Elasticity of Demand (PED) assumption of -0.30 (a 10% price increase yields a 3% demand drop).
